# Contributions

Merci de votre intérêt pour Offliner.

Ce dépôt est public pour permettre la lecture et la revue du code, mais il
**n'accepte pas de contributions** : les pull requests, correctifs et
propositions de code ne seront pas intégrés.

Vous pouvez en revanche :

- lire le code et le commenter, par exemple en laissant un commentaire sur
  un commit ;
- signaler un problème de sécurité directement à l'auteur, via son profil
  GitHub : https://github.com/SylvainAlx

Le code est protégé par le droit d'auteur, tous droits réservés : voir le
fichier [LICENSE](LICENSE).
